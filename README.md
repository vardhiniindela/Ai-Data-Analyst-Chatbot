# 🤖 AI Data Analyst Chatbot

## 🚀 Project Overview
This project is an AI-powered Data Analyst Chatbot that allows users to upload CSV files and interact with their data using natural queries. It provides insights, KPI metrics, and visualizations in a simple and user-friendly interface.

## 💡 Features
- 📂 Upload CSV dataset
- 💬 Ask questions about data (total, average, highest, etc.)
- 📊 KPI Metrics (Total, Average, Max)
- 📈 Data Visualization (Bar Chart)
- 🤖 Chat-like interaction system
- ⚡ Quick demo using sample dataset

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- Html
- NLP
- SQL Database
- Machine learning

## ▶️ How to Run

1. Clone the repository:
2. Navigate to project folder:
   cd ai-data-analyst-chatbot
3. Install dependencies:
   pip install -r requirements.txt
4. Run the application:
   streamlit run app.py
5. Open in browser:
   http://localhost:8501
